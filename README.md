# ЧAT
### Written in [kotlin](https://kotlinlang.org/).
(This project is not ready for use quite yet.)

We will try to have Wikis up as soon as possible, but bear with us for now.

ЧAT is a multi-platform chatting interface designed to put the user first, we plan to implement MOST if not all of
[discord](https://discord.com)'s features. As you can see by looking through our repo, we are quite ambitious in our concepts
and this project may not work out as planned, but we hope it does and becomes a truly great platform to use.

now, the architecture will be where a server maintainer sets up a server, and the client types their ipv6/uri to connect to them and chat.
ЧAT will have tools for server managers to moderate clients and set up automatic safeguards to prevent people from breaking server rules.

ЧAT will follow a permissions based architecture where every user has roles, you take the permissions of your top role + any permissions below it that aren't explicitly negated by roles above it.
